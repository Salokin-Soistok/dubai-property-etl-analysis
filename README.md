# Dubai Property ETL & Analysis

A Python data engineering project that cleans, transforms and explores
Dubai property sales data.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Overview

The project implements an ETL pipeline for a dataset containing more
than 81,000 Dubai property transactions.

The pipeline performs:

- Data profiling
- Duplicate removal
- Missing-value handling
- Categorical standardisation
- Datatype conversion
- Unrealistic-value filtering
- Feature engineering
- Exploratory data analysis
- Data visualisation

## Feature Engineering

A `price_per_sqm` feature was created to support comparison of property
values across different property types and locations.

## Results

After cleaning and transformation, the dataset contained approximately
75,000 records ready for exploratory analysis.

Analysis examined:

- Sale prices across property subtypes
- Average property prices across Dubai areas
- Pricing distributions and outliers

## Dataset

The original dataset used for this academic project is not distributed
